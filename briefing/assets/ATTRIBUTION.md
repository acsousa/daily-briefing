[Pixabay Content License](https://pixabay.com/service/license-summary/) (free for

These files are **not stored in git** — `./install.sh` downloads them from the
GitHub Release (`briefing-music.zip`). If they're absent, the renderer falls back to
a generated synth bumper, so the pipeline still works. Drop your own no-lyric `.mp3`s
into `briefing/assets/` to personalize the rotation.
